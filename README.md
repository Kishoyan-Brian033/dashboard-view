# Dashboard Sidebar Project

## Project Overview
This project is a simple dashboard sidebar layout built with HTML and CSS. It features a collapsible sidebar with navigation links, a user profile section, and a header with a toggle button to expand or collapse the sidebar.

## Project Structure
- `index.html`: The main HTML file containing the structure of the dashboard sidebar, header, and navigation links.
- `ty.css`: The CSS file that styles the dashboard layout, including the sidebar, header, user profile, and responsive toggle behavior.

## Features
- Sidebar with navigation links including Dashboard, Message, Comment, About, Setting, and Logout.
- User profile section with a user image and name.
- Header with a toggle button to collapse or expand the sidebar.
- Smooth transition effects for sidebar width and hover states.
- Uses Font Awesome icons via CDN for navigation and header icons.

## How to Use
1. Open the `index.html` file in any modern web browser.
2. Use the toggle button in the header to collapse or expand the sidebar.
3. Click on the navigation links to navigate (currently linked to `#` placeholders).

## Dependencies
- Font Awesome 4.7.0 CDN for icons: Included in the `<head>` of `index.html`.

## Notes
- The sidebar collapses to a smaller width hiding the user profile and navigation text, showing only icons.
- The project uses simple CSS transitions for smooth UI effects.
